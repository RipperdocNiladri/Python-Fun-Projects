# 🔐 Password Generator

A secure and customizable Password Generator built with **Python**. This project includes both a **Command-Line Interface (CLI)** version and a **Tkinter GUI** version, allowing users to generate strong random passwords with ease.

---

## ✨ Features

### 🖥️ CLI Version (`P-generator.py`)

- 🔐 Generate secure random passwords
- 📏 Custom password length
- 🔠 Include uppercase letters
- 🔡 Include lowercase letters
- 🔢 Include numbers
- 🔣 Include special characters
- 🎲 Generate multiple passwords at once
- ⚠️ Input validation
- 🔄 Generate passwords repeatedly without restarting the program

### 🪟 GUI Version (`P-generator_tkinter.py`)

- 🎨 Simple and user-friendly interface
- 📏 Password length slider
- ☑️ Select character types with checkboxes
- 🔐 Secure password generation using Python's `secrets` module
- 📋 Copy generated password to clipboard
- ⚠️ Warning messages for invalid selections
- 🚀 One-click password generation

## 🚀 How to Run

1. Clone the repository.

```bash
git clone https://github.com/RipperdocNiladri/Python-Fun-Projects.git
```

2. Navigate to the project folder.

```bash
cd Python-Fun-Projects/Password_Generator
```

3. Run the CLI version.

```bash
python P-generator.py
```

or run the GUI version.

```bash
python P-generator_tkinter.py
```
